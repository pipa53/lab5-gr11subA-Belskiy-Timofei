# Лабораторная работа №5: Модули ядра Linux

## **Суть работы**
В рамках лабораторной работы были выполнены следующие задачи:

1. **Разработка Hello World модуля**:
   - Создан простой модуль ядра, который выводит сообщения при загрузке (`insmod`) и выгрузке (`rmmod`).
   - Реализована поддержка параметров командной строки (например, `message="Custom_greeting_from_my_module"`).

2. **Создание файла `/proc/student_info`**:
   - Разработан модуль, который создаёт файл `/proc/student_info`.
   - Файл содержит информацию о студенте (имя, группа, подгруппа), время загрузки модуля (в тактах `jiffies`) и счётчик обращений к файлу.
   - Счётчик увеличивается на `1` при каждом чтении файла.

3. **Реализация символьного устройства `/dev/mychardev`**:
   - Создано простое символьное устройство `/dev/mychardev`.
   - Устройство поддерживает запись данных в буфер ядра (максимум 1024 байта) и чтение данных из буфера.
   - Логируются события открытия и закрытия устройства.

## **Краткое описание файлов**

### **Задание A: Hello World модуль**
- **hello_module.c**:
  Простой модуль ядра, который:
  - Выводит сообщение `"Hello from [Бельский Тимофей] module!"` при загрузке.
  - Выводит сообщение `"Goodbye from [Бельский Тимофей] module!"` при выгрузке.
  - Поддерживает передачу параметра `message` через командную строку.

### **Задание B: Файл `/proc/student_info`**
- **proc_module.c**:
  Модуль, который создаёт файл `/proc/student_info` с информацией:
  - Имя студента: `"Бельский Тимофей"`.
  - Группа и подгруппа: `"11, A"`.
  - Время загрузки модуля (в тактах `jiffies`).
  - Счётчик обращений к файлу (`Read count`), который увеличивается при каждом чтении.

### **Задание C: Символьное устройство `/dev/mychardev`**
- **chardev_module.c**:
  Модуль, который реализует символьное устройство `/dev/mychardev`:
  - Поддерживает запись данных в буфер ядра (максимум 1024 байта).
  - Поддерживает чтение данных из буфера.
  - Логирует события открытия и закрытия устройства.

## **Как использовать**
### **Сборка проекта**
```bash
make all
```

### **Запуск программ**
1. **Задание A: Hello World модуль**
   ```bash
   sudo insmod hello_module.ko
   dmesg | tail -5
   sudo rmmod hello_module
   ```

2. **Задание B: Файл `/proc/student_info`**
   ```bash
   sudo insmod proc_module.ko
   cat /proc/student_info
   sudo rmmod proc_module
   ```

3. **Задание C: Символьное устройство `/dev/mychardev`**
   ```bash
   sudo insmod chardev_module.ko
   sudo mknod /dev/mychardev c <MAJOR> 0
   sudo chmod 666 /dev/mychardev
   echo "Hello" > /dev/mychardev
   cat /dev/mychardev
   sudo rmmod chardev_module
   ```

### **Очистка скомпилированных файлов**
```bash
make clean
```

## **Ключевые выводы**
1. **Модули ядра**:
   - Модули позволяют динамически расширять функциональность ядра без перезагрузки системы.
   - Важно освобождать все ресурсы в функции `module_exit()`.

2. **Файловая система `/proc`**:
   - `/proc` предоставляет доступ к информации о состоянии ядра и процессов.
   - Реализован файл `/proc/student_info`, содержащий данные о студенте и счётчик обращений.

3. **Символьные устройства**:
   - Реализовано устройство `/dev/mychardev`, которое поддерживает запись и чтение данных.
   - Логирование событий помогает отслеживать работу устройства.

4. **Безопасность и надёжность**:
   - Использованы безопасные функции `copy_to_user()` и `copy_from_user()` для взаимодействия с пользовательским пространством.
   - Все ошибки обрабатываются корректно, чтобы избежать kernel panic.
